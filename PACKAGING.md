# Release contents

This release contains the MA-FPPO main-experiment implementation and 49 training recipes. Training defaults remain 0, 1, and 2. Historical model exports are training-seed-0 artifacts, not new three-seed runs.

Trained weights and data are distributed separately. See MODELS.md, DATA.md, and NOTICE.md. Third-party licenses are retained. A repository-wide license has not been assigned to the original research code.
